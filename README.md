# Abdullah Abu Sghaira - Personal Portfolio

This is the source code for my personal portfolio website, built to showcase my skills, projects, and professional experience. The project is a modern, responsive, and bilingual (English/Arabic) web application.

## ✨ Features

- **Bilingual Support:** Easily switch between English and Arabic.
- **Responsive Design:** Looks great on all devices, from mobile phones to desktops.
- **Dynamic Content:** Fetches project information and translations from local data sources.
- **Modern Tech Stack:** Built with the latest web technologies for optimal performance and developer experience.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (with App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [ShadCN UI](https://ui.shadcn.com/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Internationalization:** React Context API with JSON files.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js and npm (or your favorite package manager) installed.

- Node.js (v18 or later recommended)
- npm

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/Abdoocoder/Portfolio.git
    ```
2.  Navigate to the project directory
    ```sh
    cd Portfolio
    ```
3.  Install NPM packages
    ```sh
    npm install
    ```
4.  Run the development server
    ```sh
    npm run dev
    ```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
