# **App Name**: PortfolioFlow

## Core Features:

- Hero Section: Display name, title, and brief introduction.
- About Me: Showcase professional background and objectives.
- Skills Display: List technical proficiencies (HTML, CSS, JavaScript, React.js, Next.js, Firebase, Supabase, Git & GitHub).
- Projects Showcase: Highlight 'Smart Attendance Approval System' with description, tech stack, demo link, and GitHub repository.
- Experience Timeline: Detail IT experience in the municipal sector, focusing on digital transformation.
- Education Details: Include academic qualifications: Diploma in IT and Bachelor's in Business Administration.
- Career Interests: Outline career interests to align with recruiter expectations.
- Contact Information: Provide multiple contact methods for easy communication.

## Style Guidelines:

- Primary color: Deep Blue (#224C9A) to convey professionalism and trust.
- Background color: Light Grey (#F0F4F8) for a clean and modern feel.
- Accent color: Teal (#34A7B5) to highlight key information and call-to-action elements.
- Body text: 'Inter' (sans-serif) for readability and modern appeal. Headline text: 'Space Grotesk' (sans-serif) for impact.
- Use clean, professional icons to represent sections and skills.
- Implement a clear, sectioned layout with consistent spacing and visual hierarchy.
- Subtle transitions and hover effects for a polished user experience.
